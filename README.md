# Deen-Shathi
# ☾ দ্বীনসাথী

দ্বীনসাথী একটি ইসলামিক ও শরীয়াহভিত্তিক ম্যাট্রিমনিয়াল ওয়েব প্ল্যাটফর্মের Frontend Design। এই প্ল্যাটফর্মের মাধ্যমে দ্বীনদার পাত্র-পাত্রীর জন্য একটি নিরাপদ, পর্দাসম্মত এবং সহজ জীবনসঙ্গী খোঁজার অভিজ্ঞতা তৈরি করার চেষ্টা করা হয়েছে।

---

##  Features

- Responsive Navigation Menu
- Mobile Hamburger Menu
- Home Page
- About Us Page
- How It Works Page
- Contact Page
- Login Page
- Multi-step Biodata Creation Form
- Biodata Search Filter UI
- FAQ Section
- Fully Responsive Design

## Responsive Design

এই প্রজেক্টটি Desktop এবং Mobile উভয় ডিভাইসের জন্য Responsive করা হয়েছে।

Mobile device-এ:

- Hamburger Menu ব্যবহার করা হয়েছে
- Navigation Menu ডান পাশ থেকে slide করে আসে
- বিভিন্ন section screen size অনুযায়ী adjust হয়
- Form এবং Grid layout responsive করা হয়েছে
